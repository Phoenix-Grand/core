# Kubuno mobile - common

Reserved for the code shared by the Android and iOS apps: the Kotlin Multiplatform versions of the libraries of
`../android` (API client, accounts, UI components, viewers), written once and used on both systems.

Empty for now: phase 1 moved the libraries here as Android/JVM Kotlin (`../android`). Their conversion to Kotlin
Multiplatform and Compose Multiplatform, library by library, is planned in [`../README.md`](../README.md#phase-2--kotlin-multiplatform-and-ios).
